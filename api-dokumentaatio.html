REST API Reference

CardioRest API

Backend API for diary management, HRV analysis, measurements and Kubios integration. All protected endpoints require a Bearer token.

Base URL http://localhost:3000/api

🔐 Authentication

Suojatut endpointit vaativat JWT-tokenin HTTP-headerissä:

Authorization: Bearer <token>

Token saadaan kirjautumisesta (POST /auth/login). Virheellinen tai puuttuva token palauttaa 401 Unauthorized.

🔑

Authentication

POST /auth/register Rekisteröi uusi käyttäjä
Request Body
KenttäTyyppiPakollinenKuvaus

POST /auth/login Kirjautuminen, palauttaa JWT
Request Body
KenttäTyyppiPakollinenKuvaus
usernameString✱Käyttäjätunnus / sähköposti
passwordString✱Salasana
Responses
200 OK 401 Unauthorized 
"token": "eyJhbGciOiJIUzI1NiIsInR5cCI6IkpXVCJ9...",
"user": {
  "user_id": 1,
  "name": "Matti Meikäläinen",
  "email": "matti@example.com",
  "role": "patient"
}
POST /auth/kubios-login Kubios-kirjautuminen

Kirjautuu Kubios-palveluun ja tallentaa Kubios-session tokenin. Tarvitaan ennen Kubios-datan hakemista.

Request Body
KenttäTyyppiPakollinenKuvaus
usernameString✱Kubios-käyttäjätunnus
passwordString✱Kubios-salasana
Responses
200 OK 500 Internal Server Error 
// 500 — Kubios-kirjautuminen epäonnistui
"error": "Login with Kubios failed"

Users

GET /users/profile 🔐 token Hae oma profiili
Responses
200 OK 401 Unauthorized 
"profile": {
  "id": 1,
  "name": "Matti Meikäläinen",
  "email": "matti@example.com",
  "role": "patient",
  "created_at": "2026-04-29T10:00:00.000Z"
}
PATCH /users/profile 🔐 token Päivitä profiili

Voidaan lähettää vain muutettavat kentät. Roolia tai salasanaa ei voi muuttaa tätä kautta.

Request Body
KenttäTyyppiPakollinenKuvaus
nameString—Uusi nimi
emailString—Uusi sähköposti (täytyy olla uniikki)
Responses
200 OK 400 Bad Request 401 Unauthorized 
"success": true
// 400 — sähköposti jo käytössä
"error": "Sähköposti on jo käytössä toisella käyttäjällä"
DELETE /users/profile 🔐 token Poista oma tili
Responses
200 OK 401 Unauthorized 
"success": true

Diary

Analysis

POST /analysis/sync 🔐 token Synkronoi analyysit Kubioksesta

Hakee HRV-analyysit Kubios-palvelusta ja tallentaa ne paikalliseen tietokantaan. Vaatii, että Kubios-kirjautuminen on tehty ensin (POST /auth/kubios-login).

Responses
200 OK 401 Unauthorized 500 Internal Server Error 
"synced": 3,
"message": "Analyysit synkronoitu"
GET /analysis/ 🔐 token Hae tallennetut analyysit

Palauttaa paikallisesta tietokannasta haetut HRV-analyysit.

    "sleep_score": 78,
